Firefox 新鮮事

  • 全新功能

    分割畫面變得更好用了：現在可在任何連結上按右鍵，選擇「用分割畫面開啟鏈結」，將連結與目前分頁並排開啟。建立分割畫面時也可搜尋已開啟分頁，並可透過分頁右鍵選單中的「反轉分頁順序」快速交換兩側位置。

  • 全新功能

    現在可一次分享多個分頁。選取多個分頁後按右鍵，（在 Windows 與 Linux）選擇「複製 X 個鏈結」，（在 macOS）選擇「分享」→「複製 X 個鏈結」。貼到支援 rich text 的應用程式時，會同時包含頁面標題與網址，方便閱讀。

  • 全新功能

    現在可使用 Firefox 內建的 PDF 編輯器重新排序、複製、貼上、刪除與匯出 PDF 頁面。

  • 全新功能

    在 Firefox 桌面版試用即時、隱私的翻譯功能：開啟 about:translations 頁面，或在網址列輸入「translate」並點擊快速動作捷徑前往。

  • 全新功能

    Linux 現在支援 GTK emoji picker，使用者可透過系統快捷鍵（通常是 Ctrl+.）插入 emoji。

  • 全新功能

    透過 Microsoft Store 安裝 Firefox 的 Windows 使用者，現在也可以使用 Firefox Web Apps。

  • 全新功能

    新的 Firefox 設定檔 管理系統現在開放給包含 Windows 10 的所有使用者。

  • 全新功能

    將設定檔備份到檔案現在開放給所有 Windows 10 與 Windows 11 使用者，包含使用新版設定檔管理系統的使用者。

  • 全新功能

    Firefox 現在為 Red Hat、Fedora、openSUSE 與其他 RPM-based Linux 發行版使用者提供新的 .rpm 套件。

  • 全新功能

    當網站要求使用你的位置，但 Windows 設定尚未允許 Firefox 存取位置時，Firefox 現在會提示你到 Windows 設定啟用位置存取。此行為先前只限部分 Windows 11 版本，現在適用於所有受支援的 Windows 版本。

  • 全新功能

    內建 VPN 現在開放給加拿大使用者。注意：企業版環境不包含此功能。

    目前提供地區：加拿大、法國、德國、英國、美國。

    某些新的 Firefox 功能採行逐步釋出（progressive roll out），意味著某些使用者會比其他人更早看到此功能。如此有助於獲取早期回饋，迅速發現錯誤與改善行為，從而提升整體 Firefox 使用者的體驗。

  • 修正

    修正 macOS 啟用封閉模式（Lockdown mode）時，網頁內容中的 emoji 字元無法顯示的問題。

  • 修正

    多項安全性修正。

  • 變更

    如果你偏好從右鍵選單建立分頁群組，現在可在「設定」→「分頁」中關閉「將分頁拖曳到一起，即可建立分頁群組」。

  • 企業版

    你可以在 Firefox 150 企業版版本資訊 中找到政策更新與企業版相關的錯誤修復資訊。

  • 開發功能

    Firefox 150 開發者資訊

  • 開發功能

    pseudo-class 切換面板新增「特定元素」區塊，包含只會對具有 open 狀態元素（例如 <dialog>）顯示的 :open pseudo-class。既有的 :visited 也移入此區塊，因為它只適用於 <a> 與 <area> 元素。（深入了解）

  • 開發功能

    Document.caretPositionFromPoint() 現在只有在新加入的 shadowRoots 選項傳入對應 ShadowRoot 時，才會回傳 shadow DOM 內的位置。

  • 開發功能

    開發者工具的網路監控器，現在會標示使用非 Mozilla Root CA Program 內憑證機構簽發憑證的連線。

  • 網路平台

    Firefox 現在支援 ariaNotify API，可用更直覺且可靠的方式發送無障礙通知（例如給螢幕閱讀器），作為 ARIA live regions 的替代方案。

  • 網路平台

    Firefox 現在支援媒體元件的 pseudo-classes（例如 :playing、:paused），讓網站可依媒體播放狀態設定更精準的樣式。

  • 網路平台

    新增 highlightsFromPoint() API 支援，可回傳指定位置上的所有 CSS Highlights，讓網頁與 CSS Highlights 互動。

  • 網路平台

    Firefox 現在支援將 light-dark() 用於圖片，就像用於色彩一樣，對網站支援暗色模式很有幫助。

  • 網路平台

    color-mix() 函式先前只接受兩個色彩值；此限制已移除，現在可接受任意數量的色彩。

  • 網路平台

    lazy-loaded 圖片元件若透過 srcset 定義多張圖片，sizes 屬性現在支援新的 auto 值，讓瀏覽器能依圖片元素的版面寬度自動選擇合適圖片。（深入了解）

  • 請參考此版本的完整變更清單。 你可能也想瞭解 Firefox 版本更新資訊。
