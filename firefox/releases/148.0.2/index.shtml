Firefox 新鮮事

  • 修正

    修正部分從進階設定停用「search handoff」行為的使用者，在 Firefox 首頁搜尋框輸入的查詢被錯誤導向網址列的問題。（Bug 2017049）

  • 修正

    修正部分網頁型所見即所得編輯器無法套用諸如粗體或斜體等樣式的問題。（Bug 2020927）

  • 修正

    修正即使已封鎖自動播放，YouTube 影片仍可能意外自動播放的問題，對螢幕閱讀器使用者影響尤其明顯。（Bug 2020233）

  • 修正

    修正部分用於置中的絕對定位元素（例如使用 margin: auto 搭配 inset: 0）在初次載入時顯示為靠左的問題。（Bug 2017440）

  • 修正

    修正網址列中「切換至該分頁」在無標題頁面會顯示成空白的問題。（Bug 2020341）

  • 修正

    修正在 Windows 使用 NVIDIA GPU 並啟用超解析度視訊（Video Super Resolution）時，可能導致影片畫質下降的問題。（Bug 2019515）

  • 修正

    多項安全性修正。
