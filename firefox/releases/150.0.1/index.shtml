Firefox 新鮮事

  • 修正

    修正安裝 Bitdefender 安全軟體的使用者，Facebook 與其他網站可能無法正常載入的問題。（Bug 2034178）

  • 修正

    修正拒絕地理定位權限後，第二次嘗試時 Firefox 可能再次顯示系統權限對話框的問題。（Bug 2034120）

  • 修正

    修正部分較舊的已儲存分頁群組無法再加入分頁的問題。（Bug 2031961）

  • 修正

    修正部分下拉選單一次展開顯示所有項目的版面問題。（Bug 2033117）

  • 修正

    修正 macOS 與 Windows 上以捏合或智慧縮放時，部分頁面元素的邊框與外框消失的問題。（Bug 2030043）

  • 修正

    多項安全性修正。

  • 變更

    所有 Firefox Relay 使用者現在最多可建立 50 個 email mask（先前上限為 5 個）。

  • 請參考此版本的完整變更清單。 你可能也想瞭解 Firefox 版本更新資訊。
