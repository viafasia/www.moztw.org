Firefox 新鮮事

  • 全新功能

    Firefox 首頁（新分頁）採用全新外觀與版面，為 151 至 152 之間即將推出的小工具與捷徑改進等功能鋪路。也新增多款桌布，可點選右下角的鉛筆圖示查看。

  • 全新功能

    隱私瀏覽模式現在可立即清除目前工作階段的所有資料，而不必關閉整個視窗。點選網址列右側的「結束隱私瀏覽工作階段」按鈕（火焰圖示）後，Firefox 會要求確認；確認後會清除所有隱私瀏覽資料，並開啟全新的隱私瀏覽工作階段。

  • 全新功能

    Firefox 在標準的加強型追蹤保護中強化對指紋辨識的防護，限制網站可取得的裝置與瀏覽器資訊，讓跨站追蹤更困難。常見指紋技術下可被唯一識別的使用者數量平均減少約 14%，在 macOS 上約減少 49%。

  • 全新功能

    現在可直接在 Firefox 內合併多個 PDF，將多個檔案合併為單一文件，無需離開 Firefox 或使用第三方工具。

  • 全新功能

    翻譯頁面（about:translations）現在可從應用程式選單的「更多工具」區段開啟。

  • 全新功能

    本機 Firefox 設定檔備份現在在 Linux 上也可用（先前僅 Windows），並可跨平台還原。

  • 全新功能

    在 macOS 上，透過 Apple 通用剪貼簿從 iOS 裝置複製的 URL，現在可在 Firefox 中正確貼上。

  • 全新功能

    在 macOS 上，網頁的下拉選單現在採用原生 macOS 選單樣式，與系統其他部分的外觀與行為一致。

  • 全新功能

    自動填寫地址（Address Autofill）已對荷蘭使用者開啟。

  • 全新功能

    內建 VPN 現在可選擇瀏覽位置，讓你更能控制流量在網路上的呈現方式。可從可用國家中選擇，或使用「建議」自動選擇最適合你網路的連線。

    某些新的 Firefox 功能採行逐步釋出（progressive roll out），意味著某些使用者會比其他人更早看到此功能。如此有助於獲取早期回饋，迅速發現錯誤與改善行為，從而提升整體 Firefox 使用者的體驗。

  • 修正

    修正多螢幕設定下，向網站回報錯誤螢幕解析度的問題。

  • 修正

    修正 macOS 多螢幕設定中，Firefox 視窗最大化後重新啟動可能出現在錯誤螢幕的問題。

  • 修正

    改善 macOS 上複製與貼上圖片的色彩管理。

  • 修正

    多項安全性修正。

  • 變更

    Firefox 設定（about:preferences）中的搜尋列現在更大，並橫跨設定內容區的完整寬度，方便尋找選項。

  • 變更

    將 Firefox 桌面版設定檔目錄移動、還原到其他位置或作業系統後，安裝在該設定檔中的擴充套件與佈景主題現在可成功還原。

  • 變更

    Windows 上的地理定位現在會尊重使用者的 Windows 位置權限設定，而非覆寫它；若需要，Firefox 會提示使用者啟用 Windows 權限。

  • 企業版

    你可以在 Firefox 151 企業版版本資訊 中找到政策更新與企業版相關的錯誤修復資訊。

  • 開發功能

    Firefox 151 開發者資訊

  • 網路平台

    Firefox 現在可透過 Web Serial API 管理支援序列通訊的微控制器，可用於 ESP 裝置、Raspberry Pi Pico、3D 印表機、CNC 等。Web Serial 可用於擴充套件，但目前無法在 moz-extension 情境中使用。

  • 網路平台

    區域網路存取限制現在向所有使用者逐步釋出。Firefox 要求網站在連線到你區域網路上的裝置，或你裝置上的應用程式與服務之前必須請求權限；先前此保護僅限將加強型追蹤保護設為「嚴格」的使用者。

    某些新的 Firefox 功能採行逐步釋出（progressive roll out），意味著某些使用者會比其他人更早看到此功能。如此有助於獲取早期回饋，迅速發現錯誤與改善行為，從而提升整體 Firefox 使用者的體驗。

  • 網路平台

    新的 Fullscreen Keyboard Lock API 為 requestFullscreen 新增可選參數，讓網站可要求在全螢幕時按 Esc 不會立即退出（需長按），並允許某些原先保留給瀏覽器的快捷鍵被 preventDefault。

  • 網路平台

    Firefox 改善多欄容器與列印時絕對定位元素的渲染，定位與分頁更準確。

  • 網路平台

    @container 規則現在可指定多個 container query 條件清單，而非單一條件。

  • 網路平台

    Firefox 現在支援 container style queries，可根據容器自訂屬性的計算值套用樣式；可在 @container 規則內使用一或多個 style() 函式。

  • 網路平台

    新增 CSSContainerRule.conditions 屬性，保存所有 container query 條件的陣列，用以取代僅支援單一名稱與查詢、現已淘汰的 containerName 與 containerQuery。

  • 網路平台

    更新 CSS Anchor Positioning 中隱含 anchor 的行為：position-anchor 預設為 normal；使用 position-area 時會自動套用隱含 anchor，而使用 anchor() 或 anchor-center 的 popover 現在需設 position-anchor: auto 才能啟用。

  • 網路平台

    Firefox 現在支援 Document Picture-in-Picture API，讓網頁可將內容放在置頂的彈出視窗中。

  • 網路平台

    暫時性網站權限現在會正確反映在 Permissions API 中。

  • 網路平台

    Firefox 現在支援以宣告式方式定義 shadow root 的 slot 指派行為。

  • 請參考此版本的完整變更清單。 你可能也想瞭解 Firefox 版本更新資訊。
