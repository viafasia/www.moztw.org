Firefox 新鮮事

  • 全新功能

    使用新的「分割畫面」功能，在單一視窗中並排檢視兩個頁面，方便比對資訊、進行研究、或同時處理兩個網頁。若要建立分割畫面，請選取一或兩個分頁，再選擇「新增分割畫面」或「用分割畫面開啟」。

  • 全新功能

    Firefox 現在提供免費的內建 VPN。無論你在旅行時使用公共 Wi‑Fi、搜尋敏感健康資訊，或進行私人購物，此功能都能讓你簡單獲得保護。登入並開啟後，使用 Firefox 瀏覽時，便可透過安全 Proxy 隱藏你的地理位置與 IP 位址。每月享有 50 GB 防護額度，並可針對特定網站開啟或關閉。此功能正於美國、英國、德國與法國逐步釋出。

    企業政策說明：此功能在企業版環境中不能用，也不會向套用企業政策的使用者釋出。雖然目前可手動啟用，於 4 月 7 日起管理員將可透過企業政策停用。在此之前，組織可使用 BlockAboutConfig 政策避免手動啟用。

    此功能逐步釋出中：某些新的 Firefox 功能採行逐步釋出（progressive roll out），意味著某些使用者會比其他人更早看到此功能。如此有助於獲取早期回饋，迅速發現錯誤與改善行為，從而提升整體 Firefox 使用者的體驗。

  • 全新功能

    許多 PDF 檔案的載入速度，現在得益於硬體加速而明顯加快。

  • 全新功能

    Firefox 現在會自動封鎖通知，並永久撤銷任何遭 SafeBrowsing 標示為惡意網站的通知權限，避免不安全網站在背景向使用者推送通用於廣告、垃圾訊息或釣魚的通知訊息。

  • 全新功能

    你現在可透過自訂工具列在工具列加入「分享」按鈕，方便使用 Windows 或 macOS 系統分享選項來分享目前分頁。

  • 全新功能

    自動填寫地址（Address Autofill）已對澳洲、印度、義大利、波蘭與奧地利使用者開啟。

  • 全新功能

    裝置端翻譯新增波士尼亞語、挪威書面語（Bokmål）、塞爾維亞語與泰語支援，並提升克羅埃西亞語的準確度。

  • 實驗中

    Firefox 實驗室推出「分頁註記」實驗，可在分頁上附註簡短筆記，用來記住為何開啟某頁、接下來要做什麼，或任何想稍後處理的細節。歡迎試用並到 Mozilla Connect 分享哪些好用、哪裡還能繼續改進。

  • 修正

    提升不穩定的網路環境中 HTTP/3 上傳的穩定度。

  • 修正

    多項安全性修正。

  • 變更

    「信任面板」（TrustPanel）將網址列可開啟的隱私與安全面板合併為一處，方便一次檢視目前頁面的隱私與安全設定。深入了解。

  • 變更

    已強化可在父程序載入的 JavaScript 檔案之要求，提供額外的縱深防禦，以對抗潛在威脅。

  • 變更

    在 Linux 上，若系統提供 XDG portal 檔案選擇器，Firefox 現在預設使用該選擇器替代 GTK3 版本。通常能與使用者的桌面環境整合的更好，功能也更強大。

  • 變更

    Firefox 錯誤頁面現有全新外觀，新視覺更貼近 Firefox 整體風格。重新設計的頁面創造更加一致的體驗，同時讓使用者更清楚的了解發生什麼問題。

  • 變更

    在 Windows 上，地理定位改使用現代的 Windows.Devices.Geolocation API，取代 Windows 7 定位 API。

  • 開發功能

    Firefox 149 開發者資訊

  • 開發功能

    儲存空間檢測器（Storage Inspector）於工具列新增刪除按鈕，可刪除目前選取之儲存空間內的所有項目。

  • 開發功能

    在「計算樣式」檢視中，每個與計算值相關的 CSS 宣告旁新增圖示，可跳到「規則」檢視中的對應位置。

  • 網路平台

    showPicker() 現在支援帶有關聯 <datalist> 的文字型 <input> 元素，並會顯示自動完成下拉選單。

  • 網路平台

    xywh() 與 rect() 先前已實作於 clip-path 與 offset-path 屬性；現在亦可於 shape-outside 使用。

  • 網路平台

    CSS font-family 現已支援 math 值，並預設用於 MathML 的 <math> 元素，讓開發者能指定具進階數學功能的字型；Firefox 會使用偏好設定中的襯線字型作為 math 的後備字型。

  • 網路平台

    新增支援 HTML popover="hint" 屬性。

  • 網路平台

    啟用媒體元素偽類，例如 :playing、:paused 等等。

  • 網路平台

    啟用符合標準的 HTMLMediaElement.captureStream() API。

  • 網路平台

    支援以 Android 返回鍵關閉彈出視窗與對話框，並實作 CloseWatcher API 供 script 處理相關行為。

  • 網路平台

    新的 Reporting API 提供通用的回報機制，讓網路應用程式可以一致方式進行回報依各種平台功能（例如內容安全政策、權限政策或棄用功能報告）。

  • 請參考此版本的完整變更清單。 你可能也想瞭解 Firefox 版本更新資訊。
