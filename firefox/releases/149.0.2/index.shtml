Firefox 新鮮事

  • 修正

    多項安全性修正。

  • 修正

    修正列印時部分網頁內容（例如下拉選單與特定樣式）顯示不正確的問題。（Bug 2026109）

  • 修正

    修正部分網站錯誤頁會顯示通用連線訊息，而非伺服器提供的具體錯誤代碼與說明之問題。（Bug 2023800）

  • 修正

    修正使用特定安全金鑰或 WebAuthn 進行雙重驗證時可能發生的當機問題。（Bug 2026688）

  • 修正

    修正 Linux 上使用 Wayland 時，拖曳分頁後工具列可能無法回應滑鼠點擊的問題。（Bug 2022238）

  • 修正

    修正特定圖形（SVG）中的文字顯示可能出現位移或未對齊預期位置的問題。（Bug 2024647）

  • 修正

    修正 Firefox View 的「開啟的分頁」區塊中，「傳送到裝置」選項無法使用的問題。（Bug 2023201）

  • 企業版

    新增企業政策，讓管理員可直接管理並控制 Firefox 中與 AI 相關的功能。（Bug 2019983）

  • 企業版

    修正瀏覽器首頁與啟動頁面的企業政策未正確套用。（Bug 2027888）

  • 企業版

    新增企業政策，讓管理員可停止內建 VPN 與 IP 保護功能露出供使用。（Bug 2022365）

  • 請參考此版本的完整變更清單。 你可能也想瞭解 Firefox 版本更新資訊。
