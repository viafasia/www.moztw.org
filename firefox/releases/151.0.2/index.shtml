Firefox 新鮮事

  • 修正

    修正 macOS 上智慧卡與安全金鑰可能無法自動載入憑證的問題。（Bug 2041208）

  • 修正

    修正向既有分割畫面加入另一個分頁時，分割畫面可能意外關閉的問題。（Bug 2039795）

  • 修正

    修正從網址列使用「切換到分頁」時，分割畫面可能關閉而非切換分頁的問題。（Bug 2039787）

  • 修正

    修正 Windows 上使用搜狗輸入法輸入簡體中文時可能發生的當機。（Bug 2039203）

  • 修正

    修正磁碟快取滿後 Firefox 停止快取新內容，導致每次造訪都從網路重新下載頁面與資源的問題。（Bug 2031577）

  • 修正

    修正部分網站以 JavaScript 插入 WebKit 專用樣式規則時，可能渲染錯誤或無法載入的問題。（Bug 2040693）

  • 修正

    修正部分以特定 CSS 規則設定樣式的輸入欄位與文字區域，無法正常點選與選取文字的問題。（Bug 2039504）

  • 修正

    修正網站將數字輸入欄位設為依內容調整大小時，上下按鈕可能重疊並遮住數值的問題。（Bug 2039315）

  • 修正

    修正部分網站與 Web 應用程式排序含數字字串時可能產生錯誤順序的問題。（Bug 2027078）

  • 修正

    修正於 iframe 內建立、再移入父頁面的 <select> 元素，下拉選單無法開啟的問題。（Bug 2041720）

  • 請參考此版本的完整變更清單。 你可能也想瞭解 Firefox 版本更新資訊。
